# pyproject.toml; this file records one resolution of them, so that an image
# built today and the same image rebuilt in six months contain identical code.
# The Dockerfile installs from here.
#
#   Run the app  :  pip install -r requirements.txt
#   Develop      :  pip install -e ".[dev]"     (ranges + dev tooling)
#
# Regenerate after changing the dependencies in pyproject.toml:
#
#   uv pip compile pyproject.toml --universal --python-version 3.12 #       --no-header --output-file requirements.txt
#
# --universal matters: it keeps the environment markers, so a lock generated on
# one platform is still correct on another. Resolving with plain `pip freeze` on
# Windows silently drops uvloop (marked `sys_platform != "win32"`) and the Linux
# image loses its event loop without anything failing.
#
